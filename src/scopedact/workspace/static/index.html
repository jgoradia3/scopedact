Open your private review session

After completing the README setup, run this command from the extracted ScopedAct folder. It starts the lab and opens a private sign-in link.

.venv/bin/python tools/start_native_review.py

Native setup requires Python and Ollama (macOS/Linux). Already using Docker? Run python3 tools/start_review.py instead. Follow the repository setup guide before the first start.
