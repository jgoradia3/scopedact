# Contributing

Contributions that improve clarity, deterministic testing, documentation, or
safe handling of the documented authority-lifecycle scope are welcome.

Before submitting a change:

1. Keep all examples synthetic.
2. Do not add employer or customer material.
3. Do not add external network or paid-service requirements to the core demo.
4. Do not add unpublished research-specific mechanisms, terminology, artifacts, datasets, or results.
5. Run `python -m unittest discover -s tests -v`.
6. Explain the security property and limitations of the change conservatively.
